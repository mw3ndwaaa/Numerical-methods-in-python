# Numerical methods included

## Root finding

- Bisection: guaranteed convergence for a continuous bracketed root.
- Newton-Raphson: fast local convergence when a useful derivative and starting point are available.
- Secant: derivative-free quasi-Newton iteration using two previous points.

## Numerical integration

- Composite trapezoidal rule
- Composite Simpson's 1/3 rule

## ODE solution

- Classical fourth-order Runge-Kutta (RK4)

## Data fitting

- Linear least squares solved with a matrix formulation

The examples deliberately compare numerical outputs with analytical or physical expectations where possible, so the repository demonstrates verification rather than just implementation.
